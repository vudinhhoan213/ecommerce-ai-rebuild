# Project Brief

## Sản phẩm

Website thương mại điện tử bán hàng.

## Mục tiêu

Giúp người dùng xem, tìm kiếm, lọc, chọn màu và thêm sản phẩm vào
giỏ hàng.

## Người sử dụng

- Guest: có thể xem, tìm kiếm, lọc sản phẩm và đăng nhập. Khi xem giỏ hàng,
  thêm sản phẩm vào giỏ hàng hoặc xem thông tin cá nhân, Guest được
  chuyển đến trang đăng nhập.
- Customer: có thể sử dụng tất cả chức năng của website.

## Chức năng chính

- Xem danh sách sản phẩm
- Xem chi tiết sản phẩm
- Tìm kiếm và lọc sản phẩm
- Chọn màu sản phẩm
- Quản lý giỏ hàng
- Xem thông tin cá nhân
- Đăng nhập

## Phạm vi

Project chỉ triển khai frontend.

## Ngoài phạm vi

- Backend
- Database thật
- Thanh toán thật
- Bảo mật phía server

## Công nghệ

- React
- Vite
- React Router
- React Query
- Redux toolkit
- Rxjs
- TypeScript

## Tiêu chí hoàn thành

- Các route hoạt động
- Có loading, error và empty state
- Responsive
- Lint thành công
- Build thành công
