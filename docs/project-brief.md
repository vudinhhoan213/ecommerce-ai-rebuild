# Project Brief

## Sản phẩm

Website thương mại điện tử bán hàng.

## Mục tiêu

Giúp người dùng xem, tìm kiếm và thêm sản phẩm vào giỏ hàng.
Website mô phỏng quy trình đặt hàng trên frontend.

## Người sử dụng

- Guest
- Customer

## Chức năng chính

- Xem danh sách sản phẩm
- Xem chi tiết sản phẩm
- Tìm kiếm sản phẩm
- Quản lý giỏ hàng
- Đăng nhập

## Phạm vi

Project chỉ triển khai frontend.

## Ngoài phạm vi

- Backend
- Database thật
- Thanh toán thật
- Bảo mật phía server

## Công nghệ

- React
- Vite
- React Router
- React Query
- Redux toolkit
- Rxjs
- TypeScript

## Tiêu chí hoàn thành

- Các route hoạt động
- Có loading, error và empty state
- Responsive
- Lint thành công
- Build thành công
